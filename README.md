## 🧩 Open Source: Apollo Cache Copilot

[![npm](https://img.shields.io/npm/v/apollo-cache-copilot?style=flat&logo=npm)](https://www.npmjs.com/package/apollo-cache-copilot)
[![CI](https://github.com/nihar777/apollo-cache-copilot/actions/workflows/ci.yml/badge.svg)](htapollo-cache-copilot/actions/workflows/ci.yml)

**[apollo-cache-copilot](https://github.com/nihar777/apollo-cache-copilot)** is an AI copilot aes Apollo `InMemoryCache` normalization defects in React Native, where Apollo DevTools does notexist.

**Problem:** Apollo cache defects fail silently and surface far from their cause:
- Orphaned `__ref` pointers
- Entities missing `__typename` or `id`
- `keyFields` drift that stores one entity under two keys

**What it provides:**
- `inspectDanglingRefs` to audit a cache snapshot
- `patchCache` to apply repairs to a live cache
- `cacheAgentGraph` for an inspect → reason → plan flow
- CLI (`apollo-copilot inspect <file>`) and an MCP server for Claude Desktop, Cursor and other

**Engineering:** TypeScript, Vitest tests, GitHub Actions CI, npm publishing via trusted publisand security docs.
